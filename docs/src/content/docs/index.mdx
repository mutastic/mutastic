import { Card, CardGrid } from '@astrojs/starlight/components';

<CardGrid>
  <Card title="Your tests, checked">
    Coverage says a line ran. mutastic changes that line, `>=` to `>` say, and runs the tests that
    reach it. If they all still pass, nothing checks what the line does.
  </Card>
  <Card title="The test to write">
    Each missed mutant comes with the inputs your tests used, the gap they left, a test that would
    close it, and the command that proves it closed.
  </Card>
  <Card title="Run it from your build">
    The `mutastic` command in any project, or `cargo mutastic`, `mvn mutastic:run` and
    `./gradlew mutasticRun` from your build. The same run and the same results, whichever you use.
  </Card>
  <Card title="Made for agents too">
    While your coding agent is still in the code, mutastic hands it each gap in the lines it
    changed, and the gate holds "done" until they're closed. [Coding agents](/agents/) has the
    Claude Code, Codex and opencode plugins.
  </Card>
  <Card title="Test-first, then proved">
    A test written first covers the cases you thought of. mutastic finds the ones you didn't, on
    the lines each cycle changed, while you're still in it. [Working test-first](/concepts/test-first/)
    shows where it fits in red, green, refactor.
  </Card>
  <Card title="On every pull request">
    `--since=origin/main` mutates only the lines a change touched, so a run fits in CI and judges
    the change, not the backlog. [Running in CI](/guides/ci/) has the jobs for GitHub Actions and
    GitLab.
  </Card>
</CardGrid>
