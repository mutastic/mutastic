{/* Every version on this page is `release`, the newest release tag's: none is typed in. */}

mutastic itself runs on JDK 25. The project it tests can be on JDK 17 or later: its tests run on
the JDK its build gives them, as they always do. Its tests can be JUnit 5 or 6 (Jupiter), anything
else on the JUnit Platform, or TestNG, which mutastic runs with TestNG's own engine for the
platform; a project needs nothing extra for it. TestNG's groups count as the platform's tags, so a
build that leaves out a group leaves it out of mutastic's runs too.

<Tabs syncKey="runner">
<TabItem label="Gradle">

Until the Gradle Plugin Portal lists it, add Maven Central to where Gradle finds plugins, in
`settings.gradle.kts`:

```kotlin
pluginManagement {
    repositories {
        mavenCentral()
        gradlePluginPortal()
    }
}
```

Then apply it in `build.gradle.kts`. The project's own repositories need Maven Central too, for the
`mutastic` command the tasks run:

<Code
  lang="kotlin"
  code={`plugins {
    id("io.mutastic") version "${release}"
}

repositories {
    mavenCentral()
}`}
/>

```sh
./gradlew mutasticRun
```

mutastic runs on a JDK 25 Gradle toolchain, which Gradle finds or downloads.

</TabItem>
<TabItem label="Maven">

Declare the plugin in your POM's build plugins, so its goals take the short `mutastic:` prefix:

<Code
  lang="xml"
  code={`<plugin>
  <groupId>io.mutastic</groupId>
  <artifactId>mutastic-maven-plugin</artifactId>
  <version>${release}</version>
</plugin>`}
/>

```sh
mvn mutastic:run
```

Maven can run on JDK 17. mutastic finds a JDK 25 for itself: a JDK 25 toolchain in
`~/.m2/toolchains.xml`, else the JDK Maven runs on if it's new enough, else the one
`-Dmutastic.jdk=<directory>` names.

</TabItem>
<TabItem label="Command line">

Download <code>mutastic-{release}.zip</code> from the{' '}
<a href={`https://github.com/mutastic/mutastic/releases/tag/v${release}`}>{release} release</a>,
unzip it, and put its `bin` directory on your `PATH`. It runs on the `java` in `JAVA_HOME`, or on the `PATH`, which must
be JDK 25 or later.

<Code
  lang="sh"
  code={`unzip mutastic-${release}.zip
export PATH="$PWD/mutastic-${release}/bin:$PATH"
mutastic --version`}
/>

Then, in a Gradle or Maven project's directory:

```sh
mutastic run
```

</TabItem>
</Tabs>
